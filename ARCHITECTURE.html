② R3D 扫描系统

手机 App / Web 前端 用户层

r3d_ws_bridge ROS 节点
节点名 ws_sync_sender；boost::beast WS 服务端 :8765/data（单线程）
订阅 lio_sam：odometry / cloud_registered（BEST_EFFORT）
try_sync 50ms 配对 odom↔lidar（<0.05s）→ 每连接 50ms tick 推流（pcd 10Hz）
命令分发：startRecord → 写 IPC + 拉起 ROS 栈；stopRecord → 关窗口 + 写 IPC
r3d_main 设备主控·无ROS
状态机：INIT → RUN ⇄ SCAN →（ERROR / SHUTDOWN）
IPC 线程：100ms 轮询 /tmp/shared_cmd.txt → start/stop_radar
驱动：UART 控电源板（雷达上/下电）、GPIO 控 LED；bridge_launcher 启动 ws_bridge
关机：电量<10% / 电源板请求 → latch → execlp("shutdown -h now")
image_odom_recorder 录制存档
订阅 /lio_sam/mapping/odometry → odom.txt

⇆ 两个解耦边界
① 文件 IPC /tmp/shared_cmd.txt（{"cmd":1|0}，原子 tmp+rename 写）— r3d_ws_bridge 写 → r3d_main 读：手机命令跨进程传到设备主控，触发雷达上/下电。  ｜  ② 共享时戳 ~/timeshare（16B mmap，int64 高/低 = Livox 纳秒）— livox 驱动写 → image_odom_recorder 读：让每张照片打上真实雷达硬件时间，事后与点云/里程计对齐。
1开机建图控制流（跨三模块）
  1. 手机发 startRecord → ws_bridge
  2. ws_bridge 写 shared_cmd=1 ＋ 开 3 终端拉起 livox / lio_sam / recorder
  3. r3d_main 读到 IPC → start_radar → UART 0x34 雷达电源 ON
  4. 电源板继电器给 Livox 上电，点云开始吐出
  5. lio_sam 跑起来，ws_bridge mapping_ready 后开始推流
2实时数据流（硬件→手机）
  1. Livox 点云+IMU → livox_driver2 → /livox/*
  2. lio_sam 紧耦合 → odometry + cloud_registered
  3. ws_bridge 订阅 → try_sync 时间配对
  4. WS :8765/data 50ms tick 推 odom(20Hz)·pcd(10Hz)
  5. 手机 Three.js 渲染点云 + 位姿轨迹
3离线存档流（建图产物）
  1. recorder 读 ~/timeshare 雷达时戳作主时钟
  2. 同一时戳触发 双相机抓帧 → images/cam0|1/<ns>.jpg
  3. 订阅 lio_sam odometry → odom.txt
  4. fork ros2 bag record → rosbag2/
  5. 全部落 ~/Desktop/save_pcd/<时间戳>/，事后对齐重建
